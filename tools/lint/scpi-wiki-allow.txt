# SCPI commands deliberately NOT published in the wiki reference.
#
# One command per line, exactly as it appears in the .pattern string.
# Everything after a '#' is a comment. An entry here must say WHY -- an
# unexplained line is indistinguishable from an oversight, which is the
# failure mode tools/lint/scpi_wiki_sync.py exists to catch.
#
# Prefer documenting a command (with a warning if it is dangerous or
# diagnostic) over hiding it -- CLAUDE.md's SCPI visibility principle is to
# maximise insight into device health. An entry here should mean "documented
# somewhere a command row cannot express", not "undocumented".

# These four ARE documented, in the stream-migration table's SECOND column
# (| Canonical | Legacy alias | Migration PR |) rather than as command rows of
# their own, because they are legacy aliases of the SYST:STR:* forms and
# listing them as rows would double the streaming command surface.
#
# They were previously covered implicitly: the checker also accepted any cell
# of any table. That fallback was mutation-proved to let a COINCIDENTAL cell
# anywhere in the wiki vouch for a command whose real row had been deleted
# (#807), so it was removed and these four became explicit. The trade is
# stated plainly: if the migration table is ever deleted, these four stop
# being checked rather than being flagged -- an allowlist entry is a decision
# someone wrote down, which the fallback never was.
SYSTem:StartStreamData
SYSTem:StopStreamData
SYSTem:StreamData?
SYSTem:USB:SetTransparentMode
